# GitHub Profile Searcher

## 🌐 Live Demo

**Coming soon — deployment in progress.**

## 📌 About

GitHub Profile Searcher is a simple web application that allows users to search for GitHub profiles and view their public profile information and recent repositories.

The application uses the GitHub REST API to fetch profile and repository data dynamically.

## ✨ Features

- Search GitHub users by username
- Display profile picture
- Display name and username
- Display bio
- Display follower, following, and public repository counts
- Display location and company when available
- Display up to 5 recently updated repositories
- Show repository stars and programming language
- Direct links to GitHub profiles and repositories
- Loading animation while fetching data
- Error handling for users that do not exist
- Empty-input validation
- Responsive design for mobile devices

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub REST API
- Fetch API

## 🚀 How to Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Enter a GitHub username in the search bar.
5. Click **Search** or press **Enter**.
